# Munder Difflin New Project

This project is a new standalone copy based on the supplied Munder Difflin project.

It preserves the source project's application structure, UI, multi-agent workflow, terminal/PTY integration,
office-floor visualization, memory/hive architecture, provider integrations, tests, and build configuration.

Package name has been changed to `munder-difflin-new` and version reset to `0.1.0`.
